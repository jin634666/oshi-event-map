# 推し活イベントマップ

アニメ・漫画・ゲームのコラボカフェ、展示会・原画展、POP UP SHOP を、開催地マップと開催状況で一覧にする非公式ファンサイトです。

- イベント情報は `events.js` にあり、毎週月曜 7:00（日本時間）に自動更新されます。
- 変更履歴は [UPDATE_LOG.md](UPDATE_LOG.md) を参照してください。
- 当サイトは非公式のファンサイトで、掲載している作品・企業・主催者とは関係ありません。

- 美術館の展覧会データ（`exhibitions.js`）も置いています。このPC用アプリ「BHQ美術館めぐり」が読み込み、毎週月曜 8:00（日本時間）に自動更新されます。変更履歴は [EXHIBIT_LOG.md](EXHIBIT_LOG.md)。
